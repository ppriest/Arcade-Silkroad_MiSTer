MAME 0.289, silkroad.cpp. scripts/sprite_load.py: sprite RAM dumped at every vblank start
(the list the frame just drawn used), the same input stimulus as write_timing_mame.txt.
Counts are 16-pixel sprite tile rows per visible line (lines 16-239), geometry from
draw_sprites() (192-232), list walked to the 0xFF00 end marker.

  rows     every strip whose Y span covers the line (no X test)
  visible  only tiles overlapping X 50..429
  --blank  visible rows that are not all pen 0

Findings:
- Worst line in every run: 56 tile rows, all visible. No run parks entries off-screen in X:
  the end marker stops the list, so an X test saves little here.
- Non-blank visible rows: at most 43 (attract), 35 (2400 frames of play), 54 (9000 frames).
- Budget at 48 MHz, 3072 clk a line: 56 sprite rows plus 75 tilemap rows (three layers,
  25 tiles each) is 131 rows of 12 bytes, about 23 clk a row on one SDRAM port.
